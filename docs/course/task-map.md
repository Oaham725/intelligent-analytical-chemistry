# 分组任务地图

本书的最小维护单元是一个章节。每组可在该章节内拆分为“正文论证、代码与数据、知识图谱、交叉评审”四项工作，但一次 Pull Request 必须围绕一个清楚的问题，避免把无关修改堆在一起。

无论认领哪一章，每个组的年度交付都必须包含：一幅解释基础知识的可编辑 SVG 图；一张有来源链接的前沿更新卡；至少一道面向下一届学生的传承题。下表的“最低可交付成果”是在此基础上增加的本章特定任务。

## 18组标准方案

| 组别 | 认领章节 | 本组核心问题 | 最低可交付成果 |
|---|---|---|---|
| G01 | 第1章 智能测量导论 | 如何把 AI 放回“样品—测量—信号—模型—决策”闭环？ | 1个真实分析任务拆解案例；导论知识图谱修订 |
| G02 | 第2章 化学数据 | 原始仪器数据如何成为可建模的数据对象？ | 1个数据审计与预处理练习；数据字典或元数据示例 |
| G03 | 第3章 化学计量学 | 矩阵、秩、逆、SVD、PCA 与 PLS 如何服务于信号分解与定量？ | 线性代数推导核查；PCA/SVD 或 PLS 可运行练习 |
| G04 | 第4章 机器学习 | 模型为何会泛化失败，如何避免数据泄露？ | 基线模型对比；分组划分或校准曲线练习 |
| G05 | 第5章 实验设计 | 如何以多变量实验替代单因素试错？ | 析因/正交或响应面案例；实验设计代码 |
| G06 | 第6章 分子表征 | 如何让结构表示保留与性质相关的化学信息？ | 描述符或分子图案例；表示选择说明 |
| G07 | 第7章 深度学习 | CNN、Transformer、GNN 的归纳偏置分别适合何种化学数据？ | 一个可解释的模型比较或小型实现 |
| G08 | 第8章 生成与扩散 | 生成模型怎样用于反演、去噪和不确定性表达？ | 条件生成/去噪案例；失效边界说明 |
| G09 | 第9章 智能谱学 | 预处理、校正与模型如何共同提高谱学结论质量？ | 一套谱图处理流程；波段或误差分析 |
| G10 | 第10章 MS、色谱、NMR | 如何将分离、谱库检索和结构约束组织为结构解析证据链？ | 谱库匹配或峰表处理案例；结构判断流程图 |
| G11 | 第11章 化学成像 | 空间分辨、光谱维度和图像质量如何共同决定结论？ | 图像/高光谱处理案例；质量评价示意图 |
| G12 | 第12章 生物分析 | 生物样品的动态性、批次效应和多尺度性如何进入模型？ | 一个生物分析数据案例；批次效应讨论 |
| G13 | 第13章 多模态分析 | 不同测量模态何时互补、何时引入新偏差？ | 融合策略比较；缺失模态处理方案 |
| G14 | 第14章 标准化与 FAIR | 为什么模型跨仪器、跨批次或跨实验室会失效？ | 校准迁移或元数据案例；标准化检查表 |
| G15 | 第15章 可信智能分析 | 如何报告不确定度、适用域和潜在混杂因素？ | 失败样本分析；适用域或置信度练习 |
| G16 | 第16章 科学大模型与智能体 | 大模型怎样在工具与约束下参与分析任务？ | 一个受限工具调用流程；核验清单 |
| G17 | 第17章 强化学习与自主实验室 | 什么情况下实验问题是连续决策而非一次性优化？ | 状态—动作—奖励建模；安全约束案例 |
| G18 | 第18章 世界模型与数字孪生 | 如何预测“操作—样品状态—仪器信号”的动态关系？ | 简化测量系统模型；虚拟实验或反事实案例 |

| T02 | 3 | 化学计量学与矩阵计算 |
| T03 | 4–5 | 建模泛化与多变量实验设计 |
| T04 | 6 | 分子表示与结构—性质关系 |
| T05 | 7–8 | 深度学习与生成式反演 |
| T06 | 9 | 光谱信号与智能谱学 |
| T07 | 10 | 分离、谱图与结构解析 |
| T08 | 11 | 化学成像与空间数据 |
| T09 | 12 | 生物分析与多组学 |

## 每组的任务拆分建议

| 子任务 | 建议负责人 | 验收要点 |
|---|---|---|
| 内容主笔 | 1–2人 | 改动服务于明确问题；术语、推理、公式和案例准确 |
| 代码与数据 | 1人 | 从干净环境运行；有输入、输出、注释和预期现象 |
| 图谱与图表 | 1人 | SVG可编辑；优先解决一个基础知识难点；图与文字共同解释一个关系，不重复罗列 |
| 交叉评审 | 1人轮换 | 审查另一组 PR，指出至少一项可验证问题 |

具体认领状态由<a href="#/docs/course/team-register">本学年认领表</a>记录；实际工作以仓库 Issue 和 Pull Request 为准。
