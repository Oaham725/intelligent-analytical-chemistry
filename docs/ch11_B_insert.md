# 第11章案例补充：成员 B 技术稿

## 从像素光谱到组分类别图

普通灰度图的像素是一个强度值，RGB 图通常有三个颜色通道；高光谱化学图像的每个位置 (x,y) 对应一条随光谱通道变化的曲线。数据可写成 H×W×B 立方体。固定一个光谱通道得到二维切片；固定空间位置得到像素光谱。把模型给出的每条光谱类别放回原坐标，就得到空间类别分布图。

本案例依据 Abdolghader 等发表于 2021 年的 UHRED 研究。论文以带噪光谱同时作自编码器输入与重建目标，通过低维瓶颈提取多像素共享的光谱结构，再在潜在空间应用 k-means。无监督指训练不依赖干净光谱标签；one-shot 指只需一个高光谱视野，而不是一个像素或一次优化。

## 本组实现与原方法的区别

本组保留“像素光谱→卷积自编码器→潜在特征聚类→恢复空间图”的思路，但采用两层卷积编码器、6维潜在空间及插值解码器，以便 CPU 教学运行。原论文包含四层卷积、池化及转置卷积结构，原作者矿物脚本为20维潜在空间。本组不声称精确复现原网络或论文指标。

使用作者矿物数据的 FOV1 与 FOV2；空间每4像素取样、光谱每3通道取样。抽样是教学计算量折中，可能丢失细小空间结构与窄谱峰，不是图像质量提升。原通道没有在本案例中擅自标成拉曼位移。

训练集单独拟合全局均值与极差，分别比较原始数据、5通道移动平均和简化卷积自编码器。三种方法的 k-means 均只用训练像素拟合，FOV2 不用于选择模型。真实数据图中标记为 Cluster 0/1/2；没有独立参考谱匹配，不直接命名为石英、长石或锂辉石。

## 如何评价

真实矿物数据没有干净参考和像素级真值，因此图像平滑、聚类成片或模型与原始数据接近，均不能单独证明去噪正确。应查看各簇的原始平均光谱、代表像素光谱，以及强响应异常区域。真实数据“改变量图”展示处理相对原始输入的变化，不是已知真实误差。

另提供具有已知真值的模拟三组分光谱立方体，比较高斯噪声标准差0.08、0.20、0.40下的结果。报告光谱 RMSE、PSNR、SAM、最大峰高误差、宏F1及ARI。训练使用带噪自身，干净模拟真值不进入训练或模型选择。训练标签只用于簇编号的评价对齐，不能据此声称真实数据已完成化学物质识别。

## 数据划分与可靠性

随机像素划分容易使相邻像素分处训练与测试，导致同视野测试过于乐观。空间划分增加两列缓冲区，减轻直接邻接；另用 FOV2 测试跨视野迁移。不同视野仍可能来自同一样品，不能等同于跨样品、跨仪器泛化。模型不使用空间邻域作为输入，但样品空间相关性依然存在。

原论文正文为同视野80%训练、20%验证、另一视野测试；其公开矿物训练脚本实际使用70%/30%随机划分，两者应分别注明。本组使用65%/15%/20%及空间划分，是教学扩展。

## 结论适用范围

类别图不等于浓度图。k-means 每个像素仅分到一簇，混合像素可能被强制归类；光谱峰形和相对强度也可能被网络改变。原论文明确模型不是严格定量设计，定量浓度、真实矿物名称和更广泛泛化均需额外验证。
