# 成员 B 汇报讲稿与演示顺序

1. **数据是什么（约40秒）**：一个像素不是一个亮度，而是一条光谱。展示真实数据某通道图及代表光谱，说明H、W、B。
2. **方法是什么（约60秒）**：带噪光谱输入，自编码器压缩和重建，潜在特征接k-means，类别放回空间位置；说明是简化UHRED思路，不是原作者网络精确复现。
3. **怎么保证公平（约40秒）**：训练集拟合归一化和聚类中心；比较原始、移动平均、卷积AE；FOV2完全不参与拟合。
4. **结果怎么看（约60秒）**：打开真实数据viewer，切换随机/空间划分；展示组分类别图及各簇原始平均光谱。颜色不是已确定的矿物浓度。
5. **有答案时怎样评价（约60秒）**：打开模拟数据质量汇总图，说明噪声水平、RMSE和宏F1。按真实运行结果讲优劣，不能预设深度学习一定最好。
6. **局限（约40秒）**：真实矿物无干净/类别真值；相邻像素相关、同一样品不同视野的限制；饱和像素、混合组分、抽样丢信息及非定量输出。

现场演示不必重新训练：直接打开 results/real/viewer.html 和 results/synthetic/viewer.html；如需展示代码，依次指向 prepare_real.py、run.py 的划分、train、KMeans 和 quality。

回答“为什么没有真实准确率”：没有逐像素真实标签，不能用自己的聚类输出当答案；通过模拟真值评价流程，通过真实谱形和后续参考谱验证化学解释。

回答“为什么不直接叫锂辉石”：原论文通过参考矿物拉曼谱进行解释；本组没有完成相同标定和独立匹配，所以只命名Cluster。
