# 智能分析化学

> 从化学测量学到自主科学系统

本教材以可信化学信息为主线，系统连接采样、仪器测量、信号处理、化学计量学、机器学习、智能仪器和自主实验系统。全书不是通用AI算法汇编，而是用分析化学的问题意识组织算法、代码与实验决策。

## 全书主线

**样品状态感知 → 测量策略选择 → 数据采集 → 信号增强 → 化学解释 → 不确定度评估 → 下一步实验决策**

## 阅读方式

- 章节正文：按左侧目录顺序学习。
- 代码练习：每章均提供可运行Python文件。
- 知识图谱：每章单独保存SVG矢量图。
- Word稿：每章均可下载出版格式初稿。

## 课程共建

本网站同时是一项面向课程的大作业：学生不是在另写一篇与教材脱节的报告，而是在一个真实、可追溯的开源教材仓库中完成改进。每个小组认领一个章节模块，围绕**内容、代码、知识图谱与同行评审**提交可合并的成果；后续学年在已有版本上修订，而非从零开始。
