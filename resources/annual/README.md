# 年度资料、传承题与引文

## 归档原则

1. PDF 文件保持原授课顺序和清楚的文件名，例如 `01_智能测量导论.pdf`；不要以截图或网盘临时链接替代。
2. 每道传承题都应写明对应章节、题型、考查目标、题干、答案要点和必要的数据/代码链接；题目面向下一届，不写入本届学生的个人信息。
3. 更新引文优先使用 DOI、出版社、数据库、期刊官网、标准组织或仪器/软件官方文档链接。仅用于背景说明的网页，不替代关键方法或结论的原始来源。
4. 每年新建一个以 `YYYY-YYYY` 命名的目录，不覆盖前一学年的资料。
