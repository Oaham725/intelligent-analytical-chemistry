# 留给下一届｜G10 传承题（含答案与评分）

对应第10章，2026–2027学年。以下均为原创教学题；题1数据是随包构造的模拟数据，非真实仪器或谱库记录。参考：课程第10章及本包章节补充。数据与代码位于 `code/ch10_g10/`。

## 题1：谱库第一名可以直接写进鉴定报告吗？（计算与决策，20分）

考查目标：对齐、LRI计算、谱库相似度与独立证据的区别、拒判边界。

程序升温 GC–EI–MS，批次 B 的锚点相对参照分别为6.20→6.00、8.20→8.00、10.20→10.00 min。C8与C9烷烃在参照中的保留时间为6.00和8.00 min。未知 U01 在批次B为7.80 min。参考 RI：A=880、B=910、C=935，方法条件假定一致。

在 m/z=[51,65,77,91,106] 上，未知 x=[8,12,16,100,28]，A=[9,10,18,100,25]，B=[8,12,16,100,28]，C=[12,22,30,100,65]。相邻两个峰的时间7.60、7.90 min，基线峰宽均0.20 min。

1. 求对齐平移量、未知的校正保留时间、LRI和两峰Rs。（5分）
2. 求 x 与A、B、C的普通余弦并给出谱图排名。（4分）
3. 使用 S=0.7cos+0.3exp[−0.5(ΔRI/15)²] 排序。可否写“A已确证”？说明下一步。（5分）
4. 若Rs降为0.70，或真实固定相与库中不同，你应如何处理？（3分）
5. 把 RI 容差σ由15改为60，报告首选和前两名差。若差小于0.05应作何决定？（3分）

### 答案与评分要点

1. δ=median(0.20,0.20,0.20)=0.20 min（1分）；t校正=7.60 min（1分）；LRI=100[8+(7.60−6)/(8−6)]=880（2分）；Rs=2×0.30/0.40=1.50（1分）。LRI无量纲，用程序升温线性式。
2. cosA约0.9992，cosB=1，cosC约0.9511；B>A>C。每个数1分，排名1分，精确结果以随包脚本为准。
3. S_A约0.9994，S_B约0.7406，S_C约0.6661，A>B>C（排序及理由2分）。仅说明A为优先验证候选，不能确证（1分）；建议同条件标准品保留与EI谱比较，并回查纯度或用分离馏分NMR区分结构（2分）。
4. Rs低时先排查共洗脱，反卷积或改善分离再检索（2分）；固定相不同则RI不可直接套用，需找可比参照/重测（1分）。
5. σ=60时 A仍略高于B，但差约0.0347&lt;0.05，应拒绝唯一输出（2分）；说明结果对人为容差敏感（1分）。

可接受的数值误差：余弦和融合分数在0.001内。不能将融合分数解释为后验概率。

## 题2：设计能区分异构体的下一项证据（迁移与实验设计，10分）

考查目标：将“多证据融合”迁移到真实结构约束，选择针对性补测，避免学习批次捷径。

新的未知物已分离。候选H1为乙苯，H2为对二甲苯；分子式均为C8H10，现有名义质量EI谱和保留信息无法区分。当前没有NMR数据。你只能优先增加一项测量：推荐什么？预期哪些观察支持或削弱两候选？如果用机器学习模型评分，怎样防止训练与测试泄露？

### 答案与评分要点

优先采集纯化组分的¹H NMR，并明确溶剂、参照和样品量（2分）。理想一阶近似下，乙苯的乙基呈2H四重峰、3H三重峰，芳香区总积分5H（2分）；对二甲苯的两个等价甲基总计6H近似单峰，芳香区总积分4H（2分）。实际重叠、杂质与非一阶效应需回查，不能在未测量时宣称得到上述峰（1分）。按化合物或骨架分组，隔离同物质重复谱和同源样品，并保留外部批次；用打乱批次或跨批测试检查捷径（2分）。若结果仍含混则维持候选而非强行唯一鉴定（1分）。
