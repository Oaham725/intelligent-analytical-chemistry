# 2026–2027 学年传承题库

这里的题目由本届学生为下一届学生设计。题目不追求偏、怪或重复计算，而应检验一个能够迁移到真实分析问题的判断。每道题应在本页相应章节下添加：题目标题、题型、考查目标、题干、答案要点、所需数据/代码链接和贡献 PR。

## 题目质量要求

- **有对象**：给出足以作答的样品、测量条件、矩阵/谱图/图像或数据背景。
- **有判断**：不能只要求复述定义；应要求比较方法、识别假设、解释失败或完成推导。
- **有答案边界**：写出关键得分点与常见误区，而不是只放最终数值。
- **可传承**：不依赖已失效的临时网页、私人数据或本届课堂口头信息。

### ch14

### 题目：主仪器模型能否直接部署到新光谱仪？

**题型：** 情境判断 + 代码实验 + 方法选择  
**考查目标：** 区分硬件差异、输出偏差和波长依赖差异；设计独立目标域验证；识别 DS/PDS 的数据泄漏与失效条件。

#### 题干

某实验室在 A 仪器上建立了近红外定量模型。新购 B 仪器后，使用 42 个浓度覆盖较好的样品在 A、B 两台仪器上分别测量。另有 70 个 B 仪器样品完全独立，未参与模型训练或标准化拟合。B 仪器相对 A 出现：

1. 全波段响应略有增强；
2. 1450 nm 附近峰宽增加；
3. 高浓度端存在明显非线性偏差。

请回答：

1. 应首先进行哪些硬件和量值链检查？
2. 如何比较直接套用、斜率—偏差、DS 和 PDS？
3. 哪个数据集可以用于报告最终 RMSEP？为什么？
4. 如果全局 DS 的平均误差最低，但 1450 nm 相关高浓度样品持续偏差，是否可以交付？还应补充什么？

#### 答案要点

- **硬件检查：** 波长/波数准确度、吸光度/强度准确度、分辨率与仪器线形、检测器响应、环境漂移；先统一坐标轴、单位、样品身份和预处理。
- **方法比较：** 斜率—偏差只校正输出尺度；DS 学习全局光谱映射；PDS 学习局部窗口映射。必须使用同一训练边界和同一独立测试边界比较。
- **最终评价：** 只能使用未参与模型训练、DS/PDS 拟合或超参数选择的 70 个独立 B 样品；42 个传递样品只能用于拟合和内部诊断。
- **不能只看平均值：** 高浓度端和 1450 nm 相关样品的系统残差说明适用域或局部差异没有解决。应分层报告残差、增加代表性传递样品、考虑局部方法或拒绝外推，并给出模型版本和不确定度/拒绝条件。

#### 常见误区

- 认为 PDS 天然优于 DS；
- 把 42 个传递样品上的交叉验证结果当作最终部署误差；
- 只报告总体 R²，不检查高低浓度端；
- 只保存光谱矩阵，不保存仪器、单位、预处理和模型版本。
