# 2026–2027 学年传承题库

这里的题目由本届学生为下一届学生设计。题目不追求偏、怪或重复计算，而应检验一个能够迁移到真实分析问题的判断。每道题应在本页相应章节下添加：题目标题、题型、考查目标、题干、答案要点、所需数据/代码链接和贡献 PR。

## 题目质量要求

- **有对象**：给出足以作答的样品、测量条件、矩阵/谱图/图像或数据背景。
- **有判断**：不能只要求复述定义；应要求比较方法、识别假设、解释失败或完成推导。
- **有答案边界**：写出关键得分点与常见误区，而不是只放最终数值。
- **可传承**：不依赖已失效的临时网页、私人数据或本届课堂口头信息。

#### 题一　稀释、反应和仪器信号

**目标**　用体积和物质的量区分物理稀释与化学转化。

3.000 mL 反应液中有约 30.00 µmol OH⁻。泵回执为加 0.294 mL 的 0.100 mol·L⁻¹ 碱液。加液前理想净吸光度为 0.5587 A。求刚混匀时 OH⁻ 浓度与理想净吸光度，并说明结晶紫的物质的量如何变化。

**答案要点**　新加 OH⁻ 为 29.4 µmol，混合后约为 $(30.00+29.4)/3.294=18.03$ mM。加液的瞬时模型中 CV⁺ 的量不变，吸光度按 $3.000/3.294$ 缩小到 0.5088 A。后续反应才继续降低 CV⁺ 的量。

#### 题二　如何选最小可行剂量

**目标**　用物理模型的未来预测做受约束决策。

截止时刻 290 s，确认需预留 10 s。较慢情景预测加液 0.20、0.30、0.40 mL 分别在约 306、276、254 s 首次到阈值。三方案均满足容积上限，选哪个？

**答案要点**　比较预测时刻加 10 s 的结果。0.30 mL 是满足时限的最小剂量。执行后用实际回执更新体积，再用新读数确认结果。

#### 题三　回执丢失时怎样维护孪生状态

**目标**　理解实际执行和数字状态同步的关系。

控制器已经下发加液命令，样品吸光度随后下降，但没有收到泵回执。如何处理体积、状态和下一个动作？

**答案要点**　同一吸光度下降可由稀释、反应或基线引起。将加液后体积标为待核对，暂停控制和达标判断。依据命令编号核对泵日志或独立计量，确认实际执行量和时间，再重建投料账与状态。可用 <a href="../../../../assets/labs/g18/index.html" data-g18-site-href="./assets/labs/g18/index.html" target="_blank" rel="noopener">离线实验 HTML</a> 中的泵回执故障演示。
