# G17 研究方向与深度学习结合汇报

本目录归档小组的独立研究方向汇报《Pt/C催化剂纳米颗粒识别 深度学习复现与误检优化》。正文18页，参考与答辩备份2页，建议主讲约15分钟。第一页包含G17三人分工，并明确分工来源是课程第17章共建；汇报人为补忠幸。

- [可编辑PowerPoint](ptc-codex-15min.pptx)
- [便于阅读和提交的PDF](ptc-codex-15min.pdf)

PPT每页备注区已清空，不内嵌讲稿。内容包含研究背景、为什么做、对Pt/C表征的帮助、公开数据与代码流程、误检诊断、优化前后指标和研究限制。

本汇报是公开数据上的YOLOv8n简化检测复现，与[第17章强化学习和自主实验室教材](../../../../../docs/ch17.md)分别归档；不把Pt/C检测写成强化学习实验，也不替代教师正式专题课件。该目录为学生报告，不向仅收教师确认课件的 `ppt/` 目录添加文件。

## 使用与证据边界

识别模型、代码、Skill和34张公开测试图片已在本次作业本地交付包中另行提供；它们未作为本目录PPT/PDF的二进制附件重复加入课程源码。本次数据来自公开原有开发视野，并非本人实验或新盲测。平衡模式的精确率69.3%、召回率64.0%等结果只用于说明当前开发图像上的探索性改善，不直接报告纳米粒径、元素鉴定、ECSA或ORR性能。

背景论文：Genc et al., Ultramicroscopy 271 (2025), 114116，https://doi.org/10.1016/j.ultramic.2025.114116 。原数据仓库：https://github.com/ArdaGen/STEM-Automated-Nanoparticle-Analysis-YOLOv8-SAM 。
