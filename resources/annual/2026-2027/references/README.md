# 2026–2027 学年更新引文

本页记录本届对教材正文新增或修订的外部依据。每条引文应能让下一届学生直接访问；正文中的观点应与此处来源对应。需要长期保存的基础经典文献可保留，年度更新重点放在真正改变本章结论、能力边界或实践选择的进展。

## 引文记录格式

```markdown
- 作者. 题名. 期刊或机构, 年份. [DOI 或官方链接](https://doi.org/...).
  - 对应章节：第X章；用途：支撑/更新……；证据等级：原始研究、综述、标准、官方技术文档。
  - 更新 PR：#编号。
```
