# 模拟数据字典

所有数据为本作业人为构造；无真实样品身份、商业谱库摘录或真实性能标签。

| 文件 / 字段 | 类型、单位、含义 |
|---|---|
| spectra.csv / spectrum_id | 字符串；U01–U03为待测谱，A–C为匿名参考候选 |
| mz | 正整数名义m/z；本例只用51、65、77、91、106 |
| intensity | 非负相对强度；每张谱最大值为100；无噪声估计，不能作检出限分析 |
| candidates.csv / candidate_id | A、B、C，关联参考谱 |
| reference_ri | 无量纲；同固定相、同温度程序的假定教学LRI |
| source | synthetic_teaching_reference，明确参考值的身份 |
| peaks.csv / sample_id | 关联待测谱 |
| batch | 批次B；用于选择对齐锚点 |
| raw_rt_min | 原始保留时间/min；B批比参照整体晚0.20 min |
| rs | 该目标峰与相邻干扰峰的教学分辨率，预先给定，不由当前离散质谱峰表计算 |
| alkane_n | 夹持目标峰的较低正构烷烃碳数 |
| alkane_low_ref_min / alkane_high_ref_min | 对齐参照坐标下的Cₙ、Cₙ₊₁保留时间/min |
| anchors.csv / anchor_id | 已知身份的对齐标记；不可用未知物候选排名来反向拟合漂移 |
| observed_rt_min / reference_rt_min | 锚点在当前批次/参照中的时间，min |

假定GC程序升温、EI正离子、70 eV；未模拟柱长、载气、温度程序细节、仪器噪声或检测器响应，不构成可复现实验方法。真实数据需补充固定相、柱规格、温度程序、流量、离子源和仪器型号、原始文件与空白/QC。

人为情境：U01故意使谱图更像B但RI支持A；U02设置共洗脱风险；U03使RI处于A/B中间。这些情境标签仅用于教学，不用于计算准确率。

输出：ranking.csv保存每个样本每个候选的cosine、RI差、RI分数、融合分数与排序；decisions.csv保存原始/校正时间、LRI、基线首选、融合首选、差值和决策；sensitivity.csv仅改变U01的σ；run_log.json保存参数、Python版本、输入SHA256和UTC运行时间；comparison.svg可编辑地展示各样本候选得分。
